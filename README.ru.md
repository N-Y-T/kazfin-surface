# KazFin-Surface: пилот на стыке двух тем

Вопрос: насколько LLM хуже решают **одну и ту же** финансовую задачу, когда она
написана так, как в Казахстане пишут на самом деле — на русской раскладке и
вперемешку с русским?

Каждая задача существует в шести вариантах с одинаковыми числами и одним
правильным ответом, поэтому разница в точности объясняется только формой текста.

| Регистр | Что это | Как получен |
|---|---|---|
| `en` | английский, как в FinChain | шаблон |
| `ru` | русский | шаблон |
| `kk` | нормативный казахский | шаблон |
| `kk_kb` | казахский на русской раскладке (ә→а, қ→к, ң→н, і→и …) | автоматически |
| `kk_cs` | казахско-русское смешение, как в чатах | шаблон, **пишет носитель языка** |
| `kk_cs_kb` | смешение + русская раскладка | автоматически |

## Шаблоны (12)

Простые проценты · аннуитетный платёж · переплата по кредиту · остаток основного
долга · депозит с капитализацией · неустойка по договору с ограничением ·
НДС в сумме счёта · балансовая стоимость при амортизации · текущая ликвидность ·
ROE · NPV · курсовая разница по валютному кредиту.

20 экземпляров × 12 шаблонов × 6 регистров = 1 440 задач (`data/pilot.jsonl`).
Ответы проверены независимо: numpy-financial для кредитов и NPV, пересчёт
неустойки по датам из английского текста задачи.

## Самый простой путь: Kaggle

`notebooks/kazfin_kaggle.ipynb` — самодостаточный ноутбук: в нём весь код, он сам генерирует
задачи, прогоняет три модели, KazMMLU и собирает `results.zip`. Инструкция в первой
ячейке. Нужны GPU T4 x2, Internet On и секрет `HF_TOKEN`.

## Файлы

- `kk_surface.py` — замена 9 казахских букв (полная или частичная, вариант с латинской `i`).
- `templates_kk.py` — 12 шаблонов по образцу FinChain (Apache-2.0). **Казахский и смешанный текст — черновики, их нужно вычитать.**
- `generate.py` — набор задач.
- `hf_runner.py` — пакетная генерация через transformers: делит модель 8B на 2×T4, пачки ограничены по токенам, при нехватке памяти пачка делится пополам.
- `run_model.py` — прогон одной модели.
- `score.py` — разбор числа из ответа, допуск 1%, точный тест Макнемара.
- `kazmmlu_flatten.py` — линия B: казахская часть KazMMLU в нормативном написании и на русской раскладке.
- `report.py` — `results/summary.csv`, `results/by_template.csv`, `results/accuracy.png`.

## Запуск вне Kaggle

```bash
pip install torch transformers accelerate pandas matplotlib huggingface_hub
export HF_TOKEN=...            # после принятия условий Sherkala, KazLLM и KazMMLU на HF
python generate.py --per_template 20
python run_model.py --model inceptionai/Llama-3.1-Sherkala-8B-Chat --out preds/Llama-3.1-Sherkala-8B-Chat.jsonl
python run_model.py --model issai/LLama-3.1-KazLLM-1.0-8B          --out preds/LLama-3.1-KazLLM-1.0-8B.jsonl
python run_model.py --model Qwen/Qwen2.5-7B-Instruct                 --out preds/Qwen2.5-7B-Instruct.jsonl
python kazmmlu_flatten.py --model inceptionai/Llama-3.1-Sherkala-8B-Chat --limit 100
python report.py
```

Sherkala (CC BY-NC-SA 4.0), KazLLM и KazMMLU (CC BY-NC 4.0) — только для
некоммерческого использования.

## Что проверено

20 ноября 2026 ноутбук отработал на Kaggle (GPU T4 x2) на трёх моделях:
около 2 часов на модель. По ходу исправлены освобождение памяти между моделями
и разбор ответов KazMMLU (модели отвечают и кириллицей: «А», «Б»); сырые ответы
KazMMLU теперь сохраняются в `raw_std` / `raw_kb`.

## Ограничения

- ChainEval из FinChain сравнивает шаги английскими эмбеддерами; для казахского
  пока считаем только финальный ответ.
- Смешанный регистр написан вручную — это сила (естественность) и слабость
  (один автор). Стоит дать 2–3 носителям переписать часть задач по-своему.
